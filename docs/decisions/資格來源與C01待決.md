# 資格來源基礎與 C01 決策（已確認 C01）

依據：02-01、02-02、02-03、02-04、02-05。使用者決定先補資格來源與 C01，再開放草稿新增。

## 本批已確定並實作

- 固定方案表依 02-01 保存月／季／年價格及公開／草稿／封存的房源與文章額度。不新增 GB、稅務或未定分享政策；無限僅公開房源筆數無上限，以 null 表達，非 0。
- EntitlementAccount 記錄可信帳號起點；新註冊流程在同一筆建立會員操作內記錄 REGISTRATION 與 verifiedAt，因此可辨識新帳號的免費起點。不依前端 plan 欄位判斷。
- 既有會員缺少可信起點時回 UNAVAILABLE／ACCOUNT_NOT_RECONCILED，不自動回填免費、不改動舊會員或既有內容。
- EntitlementPeriod 保存來源類型（購買／贈送）、來源參照、等級、起訖、確認與撤銷時間；同來源類型與參照不得重複。這是內部權益事實，不等於付款成功或贈送核准流程已存在。未新增任何公開核發資格 API。
- 查詢僅使用目前期間有效、來源已確認、未撤銷的資格；起點包含、終點不包含，未來資格不提前生效。
- 已確認帳號且沒有目前有效資格時回免費；到期展示寬限不延長付費資格，本服務不處理公開房源的 48 小時展示或下架排程。
- 同等級多筆目前有效資格不加總額度；不同等級同時有效時回 UNAVAILABLE／OVERLAPPING_DIFFERENT_PLANS，不自行採最高等級或處理 C06 交錯規則。
- 存在目前期間有效但未確認的來源時回 UNAVAILABLE／SOURCE_NOT_CONFIRMED，不直接給付費、也不默默降為免費。
- 撤銷僅排除該來源，不刪除其他資格；帳號刪除的保存政策未決，資料關聯採 RESTRICT，不自動刪資格事實。這不是帳號刪除流程的完成。

## 不宣稱完成的部分

付款對帳／核准、退款、贈送審核／管理員權限、推薦獎勵、期間安排及交錯結算都尚未建立。正式資格寫入只能由後續可信流程提供，不能由一般會員或前端提交 confirmedAt／sourceReference。

sourceReference 需要對應後續實際核發事件／來源紀錄；目前只建立唯一性，尚無金流或案件外鍵。正式來源寫入與更動須與使用者列鎖定規則一致，並保留操作者、理由與來源證據，不能把測試樣本當成已確認付款。

因此本批是伺服器資格帳本與讀取核心，不是完整「正式付款／贈送來源已接通」。新註冊免費基礎可用；既有帳號核對及正式付費／贈送核發仍受依賴限制。已將可判定的資格查詢接入草稿新增政策；未知資格或不同等級重疊仍拒絕，不代表正式付款／贈送流程已完成。

## C01 使用者已確認

房源封存超額時禁止新增房源草稿，網站／Bot／匯入須一致使用同一核心；既有草稿仍可編輯及刪除，符合公開額度及上架條件時仍可上架，文章不受連帶影響。本次只串接已存在的草稿新增／讀取／編輯，刪除、Bot、匯入與上架流程尚未建立，不能宣稱已實作。

新增政策在會員列鎖交易內讀取資格、計數草稿與封存；封存筆數等於上限不阻擋，超過才阻擋。免費方案上限為封存 10、草稿 1；其他已確認方案從共同方案表取值。不讀文章資料、不連帶扣文章額度，回收區不計封存。

存在歷史 UNPUBLISHED 時回 503 LEGACY_LISTING_STATE_UNRESOLVED，保留內容等待核對，不自行猜測其計數分類。資格可信且可判定時才允許新增；無來源、未確認來源、不同等級重疊仍回 503。這些是尚未能可靠判定的資料，不是另增方案政策。
