# 圖片處理核心與隔離驗收

> 2026-11-06狀態註記：下文保留該批歷史規格／驗收事實，不能當作現行產品基準或最新全量測試。最新依行政資料01／02與 [目前進度](../../行政資料/進度與待辦/進度執行表.md)；套房合併、免面積來源、舊C01及無限公開等過往決策若與新版R02／02-01／02-09衝突，均已被取代。新欄位、完整上架與正式容量尚未全部接妥。

依據：02-06（格式、照片、縮圖、GPS、使用權）、02-09（原圖不長期保存、實際容量、引用與失敗處理）。本批依使用者同意，先完成供應商無關的核心及隔離測試，不開通正式儲存。

## 已實作

- 使用固定版本 sharp 0.35.5。新增依賴與 lockfile，未停用 TLS 或套件完整性驗證。
- 以實際檔頭及解碼結果確認 JPEG／PNG／WebP，不信任副檔名或前端 MIME；SVG／GIF／HEIC 等不進入處理。
- 在解碼前檢查原始位元組；以明確設定限制像素及各處理操作時間。損壞或截斷圖片不可只憑讀得出檔頭通過。
- 套用 EXIF 方向到像素，等比例產生展示圖及縮圖，不放大小圖、不裁切。技術上統一輸出 WebP，保留透明像素，品質由設定傳入。
- 重新編碼且不保留 EXIF／XMP／IPTC／ICC；輸出再次檢查，確認中繼資料未殘留後才回傳處理時間。測試使用真正含 GPS IFD 的 EXIF 照片，不只檢查假欄位。
- 原圖只在記憶體處理，不寫原圖到儲存；不承諾 JavaScript 記憶體被立即安全抹除。
- 必須明確確認照片使用權才進入存檔流程。此布林檢查不是權利真偽查核；正式 API 後續須記錄登入者、確認時間與對應資產。
- 儲存回傳內部 assetId、兩張實際位元組、尺寸及處理時間；沒有假公開網址，也未寫 MediaAsset 或 ListingMedia。

## 技術參數與未決產品邊界

maxInputBytes、maxInputPixels、展示圖及縮圖最長邊、品質、處理 timeout 均由呼叫端明確提供，沒有偷偷指定正式環境預設值。像素／時間屬資源保護，正式值需依環境與負載驗證。

測試採原檔上限 10,000,000 bytes、展示圖 100 px、縮圖 32 px 等小尺寸 fixture 設定，不代表正式圖片品質／尺寸定案。企劃的「10 MB」究竟以 10,000,000 或 10,485,760 bytes 計，仍須於上傳契約中明訂；正式端點尚未開放。

動畫 WebP／多頁圖片會回 ANIMATED_IMAGE_REQUIRES_POLICY，不默默轉為第一張。這是未定情況的暫不處理，不代表永久排除動畫的產品決策。HEIC 原企劃待核對，未自行支援。

## 隔離儲存

TemporaryImageStore 只建立 OS 暫存目錄，根目錄及資產目錄 0700，檔案 0600。不掛靜態路由、不提供 URL、不讀外部憑證，也不作正式持久儲存。

保留新 UUID 目錄後，依序寫 display.webp／thumbnail.webp，exclusive create 防止覆寫。檔案鍵限制為 UUID 與固定 variant，拒絕路徑穿越。處理失敗不產生任何存檔。

- 第二張寫入失敗：清除已保留的整組資產，不回傳成功 receipt。
- 清理也失敗：IMAGE_STORAGE_CLEANUP_REQUIRED，回傳待清理 assetId，不宣稱已釋放容量。
- 保留已明確失敗：不刪除未取得所有權的既有資產。
- 保留結果不明：供應商 adapter 必須回 ReservationOutcomeUnknownError，核心回核對目標，不盲目刪除或直接當作成功。正式雲端仍須實作查核及補償工作。
- 測試結束關閉並刪除隔離目錄；原圖、測試圖均不成為公開網站內容。

## 正式整合尚未完成

沒有新增 HTTP 上傳、公開／私有下載路由、MediaAsset／ListingMedia 資料庫整合、使用者容量扣抵、上傳重送去重、儲存補償佇列或正式服務 adapter。

正式串接仍須：登入／管理權／狀態複查、串流大小限制、使用權確認紀錄、處理併發限制、資料庫失敗後的物件清理、草稿私有存取、公開資格變更時快取／存取控制、引用與總容量交易及清理重試。不能把核心通過測試當成已可讓使用者上傳。

未選供應商、未啟用付費服務、未執行 migration 或修改資料庫；未對本機、正式環境或外部服務寫入。

## 驗收方式

圖片專用測試：`npm exec --workspace=@rental/api -- vitest run tests/image-processing.test.ts`，不依賴資料庫或外部帳號。完整測試另使用隔離 PostgreSQL 工具。

案例包含三種實際格式、比例及不放大、真 GPS／方向、XMP／透明度、位元組邊界、截斷、偽圖片、像素限制、動畫未定、無效設定、實際檔案權限與容量、使用權未確認、寫入／清理失敗、保留結果不明、路徑穿越與覆寫防護。

本次新增 25 項圖片測試，含既有案例共 177 項全部通過；型別檢查、編譯與 git diff --check 通過。既有 Prisma/pg 棄用提示仍在。本批沒有建立正式儲存帳號、公開網址、HTTP 上傳路由或 migration。
