## 可執行狀態

| API | 現況 |
|---|---|
| GET /api/v1/drafts/:id | 已接正式應用路由，僅登入管理者可讀取自己的 DRAFT |
| PATCH /api/v1/drafts/:id | 已接正式應用路由，支援缺項編輯與交易內管理權／狀態／憑證複查 |
| POST /api/v1/drafts | 已接伺服器資格帳本及已確認 C01；來源可信且狀態可判定時可新增，無資格紀錄／未確認／重疊不明時 503；草稿滿額時409；歷史封存超額不阻擋 |

第 4 步的文字與地址副本草稿新增／讀取／編輯已有可操作路徑，但圖片與公開地址確認仍未完成；不將測試注入的資格當成正式付費資格。既有草稿即使超額仍可讀取及編輯，不會因新增資格判斷失敗而阻擋這兩項操作。

## 資料契約

- Authorization: Bearer 必填，沿用登入憑證。會員身分來自後端，不接受前端指定管理者。
- body 欄位依 draftPatchSchema，地址使用巢狀address物件；utilityCharges、equipmentItems、feeItems為子集合，其餘為扁平欄位；例如 `{ "title": "新標題", "rent": 12000, "description": null }`。
- 未提交的欄位保留；null 明確清空允許為空的欄位；false與允許的0不當成未提交；月租0、標題空白等不合新規則的已填值會拒絕，陣列[]明確清空對應集合。空 PATCH 不更新時間。
- 部分選項可先存而缺必要細節：例如選押金 MONTHS 尚未填月數，可保存草稿，但不是可上架內容。
- 模式切換清除不適用的依賴值；不把舊單層當成新範圍答案，不把「無陽台」的 0 當成專用陽台數量。
- 本批金額、數量、面積採已確定R02範圍及精度檢查，不自動捨入；僅對本次觸及欄位檢查明確矛盾，不因不相關的舊資料不完整而拒絕改標題。
- body 白名單不包含 publisherId、status、moderationStatus、propertyId、isWholeBuilding、驗證／公開同意時間、firstPublishedAt、方案、資產連結或共享 Property 修改。不能藉草稿 API 上架、解除限制、換管理者或連到他人房屋。
- rentalType 明確提交時同步內部 isWholeBuilding。舊未知 rentalType／areaType 不自動覆寫，areaType 只讀回傳以保留歷史面積語意。
- 回應為 data.draft，包含允許編輯欄位、id、status、moderationStatus、areaType、建立及更新時間；不返回帳號資料、Token、共享 Property 或精確座標。
- 時間為 ISO，availableFrom 為 YYYY-MM-DD；areaPings／depositMonths 為數字。這是管理用資料，不是公開房源 DTO。
- 此 API 已支援 address 巢狀欄位的私人工作副本，詳見 docs/database/草稿地址副本與驗收.md。圖片上傳／引用／排序另有受限且可注入的核心，尚未啟用正式容量；公開地址變更、完整分組或定位尚未處理。propertyId 明確拒絕，不能為了支援地址跳過共享資料管理規則。

錯誤：401 憑證無效；404 外人或不存在（相同回覆）；409 已非草稿或額度衝突；400 欄位錯誤／禁止欄位；503 新增資格未接妥。讀取／編輯均 no-store。

## 交易與測試

先鎖定會員列，再重新確認有效憑證及帳號狀態；鎖定目標刊登列，確認仍為本人且 DRAFT。更新條件再次包含管理者及狀態，不信任 middleware 過去的檢查結果。

新增使用同一會員列鎖，在交易內取得可信政策與計數；同時搶最後一格只能一筆成功。這只保證使用本服務的路徑，後續匯入／Bot／狀態轉換也必須遵守同一交易鎖定規則。不同欄位同時 PATCH 不整列覆寫；同欄位依序寫入以後者為準，未另增未決的版本衝突政策。

所有測試在獨立暫存 PostgreSQL 執行；測試專用政策與路由只存在測試檔。已驗證缺資料、0／false／null、欄位保留、禁止欄位、外人隔離、非草稿、撤銷憑證、管理權變更、額滿、政策未定、模式切換、失敗不改資料與併發編輯。

本次共 122 項測試通過（本批新增 22 項）；型別檢查、編譯及 git diff --check 通過。既有 Prisma/pg 並行 query 棄用提示仍存在，未升級套件。

實際開發 API 亦已驗證 GET／PATCH 200、非法改狀態 400、預設新增 503。該檢查使用明確的 ORM 測試資料，沒有偽造正式資格；臨時會員與草稿已清除。本批沒有新 migration，未操作本機或正式資料庫。

## 現行C01與資格來源（2026-11-06核對）

- 歷史封存超額不阻擋草稿空位內新增；免費草稿額度3。會員列鎖內檢查可信資格與草稿計數，不再讀封存數作新增門檻。
- 缺可信資格、未確認來源、不同等級重疊仍回503；UNPUBLISHED舊資料保留，不因其存在阻擋空位內新增，也不猜轉封存。
- DraftCreationPolicy只回傳draftLimit。Bot／匯入／刪除／上架尚未有可操作流程，各入口後續須遵守共用資格及交易規則。
- 新R02已填值的0租金、超過2位小數及重填舊模糊型態均拒絕；歷史值在無關修改時保留。新欄位及子集合已接入，但完整發布檢查、費用比例與聯絡驗證尚未完成。付款／贈送核准、R07臨時額度仍未完成。
