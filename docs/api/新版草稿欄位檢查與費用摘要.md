# 新版草稿欄位檢查與費用摘要

2026-11-11（台灣時間）。產品依據：行政資料02的R02、R03與照片規則；以26298c4為實作起點。本批沒有變更產品價格、額度、P01／P02或圖片暫定規格。

## API

`GET /api/v1/drafts/:id/validation`，沿用Bearer session。只允許目前草稿持有人讀取；非本人404，未登入401，非草稿409。回應`Cache-Control: no-store`。

回應位於`data.validation`：

- `confirmedRulesPassed`：本次可由現有草稿欄位檢查的規則是否通過，**不代表可以發布**。
- `issues`：代碼、欄位路徑、規則章節；不回傳電話、LINE或私有地址值。
- `outstandingChecks`：仍需要正式身分／聯絡控制權、地址與地區核對、圖片來源證據、目前版本預覽確認及原子公開額度交易。沒有任何可用request布林值跳過這些關卡。
- `feeSummary`：資料格式及必要費用明細不完整時為null；齊全才計算純月租、每月固定必要費合計、押金、一次服務費、一次水電費及選配項目索引。其他必填尚缺仍會列在issues，不會因摘要可算就開放發布。

此GET只查詢，不改內容、狀態、時間、額度或資產。仍沒有publish路由。

## 草稿寫入

POST／PATCH新增服務費`PERCENT`模式與`percentage`（0.01～100、最多小數2位）。僅SERVICE可用比例；`paymentTiming`、`payee`保存支付時點與收款對象。草稿可缺必填明細；已填值格式錯誤則整筆拒絕。發布欄位檢查要求服務費完整，免收用NONE；收費用明確固定或比例且為ONCE，不以面議或定期租金替代。

電話／LINE格式套用現有R02驗證；Email不能單獨滿足發布聯絡管道，也不表示任何管道已驗證可聯絡。一般文字不接受HTML／可執行標記。未提交的舊欄位不因一般文字編輯而遭重寫。

費用集合沒有使用者排序承諾；用具體項目辨識，不以回傳陣列位置假定是原送入順序。新版資料使用新版集合，舊金額、自由租期與舊套房語意不推測遷移。

## 計算與儲存

- 純月租保留為搜尋／排序口徑，不改為含費總額。
- 固定必要月／季／年費先用精確Decimal累加，再於最後顯示四捨五入；季除3、年除12。一次費、押金、選配及用量／帳單費不混入固定月合計。
- 押金月數及一次服務費比例按純月租計算；不套訂閱退款／補款的取整方法。
- `guaranteedMoveInTotal`維持null，不假定首期計價或保證入住總價。
- 相容區段adapter更新選項、數值界線與月數租期、多層樓；它僅供區段往返，完整現行欄位診斷一律使用canonical draft DTO，不以區段complete當成發布完成。
- 新增第16個migration：`20261111000000_add_service_fee_percentage`。只增加欄位與服務費比例模式，不改寫歷史資料。需先套migration再啟動新版程式；本批僅在隔離測試庫套用，未套正式或常駐開發資料庫。
