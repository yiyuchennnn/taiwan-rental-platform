# 後端主流程與前端整合

2026-11-12。以74bca52為程式起點，遵循01～12的既定規則，未改價格、額度、期限、P01／P02或容量商品。

## 現在可使用的私人流程

1. POST /api/v1/auth/register、/login取得Bearer；目前不是網站cookie／CSRF流程，不把token放URL或公開資料。未有UI，本批不選網站框架。
2. POST /api/v1/me/listings，header Idempotency-Key為新UUIDv4，body為`{"draft":{"title":"草稿標題"}}`。回data.operation，取resourceId，再GET /me/listings/:id讀目前內容／revision。只有操作收據，不把私人內容快照存成重送結果。
3. PATCH /me/listings/:id/work-version，body為`{"expectedRevision":1,"patch":{"rent":20000}}`，另帶新key。草稿／封存可保存；公開內容的獨立工作版與提交修改仍未完成，不用這個入口直接改公開版。
4. 圖片使用既有/drafts/:id/images，但所有寫入需目前版本：binary POST帶`If-Match: "1"`，PUT／DELETE可用相同header或JSON body.expectedRevision，兩者同時提供須一致。POST還要UUIDv4 key、X-Image-Rights-Confirmed:true及支援格式的binary。
5. 每次圖片成功改動會更新內容revision；讀取/me/listings/:id取得新版再處理下一張／封面，不能用同一舊revision併發改圖。上傳原key同檔成功重送先查原結果，不因revision已變再次附圖；不同檔或目標同key會衝突。
6. POST /me/listings/:id/preview，body.expectedRevision。回preview.id、revision、本地缺漏及費用摘要；不占公開名額。最新預覽取代該內容先前預覽，沒有私人內容版本庫。資格／查核來源、持有人或內容變更後需重看，不讓舊確認套不同結果。
7. POST /me/listings/:id/publish，body為expectedRevision、previewId、confirmed:true，帶新key。交易核心會重核來源狀態、欄位、可信證據、地區、公開位及首刊歷史，原子保存狀態／公開投影／版本／操作／事件。**正式runtime缺查核、容量與權益生命週期來源，目前回503，不對外發布。**
8. POST /me/listings/:id/transitions，body為expectedRevision、action、confirmed:true，帶新key。已實作archive、mark-rented、to-draft、trash、restore；不是任意status PATCH，也沒有permanently-delete入口。

以上均需本人session；先鎖帳戶再鎖內容，交易內重驗。公開／私人DTO分開，不把Listing ORM整筆傳給訪客。

## 前端必須呈現的結果

| 結果 | 應處理 |
| --- | --- |
| 400欄位錯誤 | 保留表單，依欄位修正；需要完整缺漏時讀預覽／validation，不自行補0或否 |
| 400 REVISION_REQUIRED／缺key | 修正整合；不要自動取新版重送使用者未確認的內容 |
| 401 | 導登入，安全保存本地未送文字；不把token放URL |
| 404 | 不顯示他人或不存在的私人內容 |
| 409 REVISION_CONFLICT／PREVIEW_STALE | 保留本地文字，重讀、比對，再由本人確認；用新意圖的新key |
| 409 CONTENT_QUOTA_EXCEEDED | 保留原資料，說明目標狀態滿；不是圖片容量錯誤 |
| 409 IDEMPOTENCY_KEY_REUSED | 同key不能換body／目標；查原操作，不能盲目換key重做未知副作用 |
| 503查核／容量未知 | 保留草稿與原檔／原圖狀態，不假稱已公開、驗證或超額 |
| 連線中斷、結果未知 | 已知operationId可GET /me/operations/:id；否則重送原key＋原body。原收據表示當時結果，仍需重讀目前內容；後續下架不被成功重送復活 |

用戶端依code處理，不解析中文message。X-Request-Id由伺服器產生，用於回報問題；不回傳stack、證據或私有輸入值。

## 版本與兼容切換

實際createApp已停用無版本POST／PATCH /drafts，回400 USE_VERSIONED_CONTENT_COMMAND。GET／validation／圖片路徑仍在；少數舊資料／服務回歸測試明確使用legacyCompatibility，正式組裝不開啟。前端只接/me/listings命令；不是兩組可任意混用的寫入API。

新複層寫入為MULTIPLE＋明確floors，不自動把舊RANGE展開連續樓層；舊值可讀及做無關文字編輯，改該組需本人確認。單層沿SINGLE／floorFrom。車位類型新寫入為FLAT／MECHANICAL／OTHER。歷史首刊未知不阻擋其他條件合格的重刊：既有可信值保留，舊null標UNKNOWN且不填今天；新建才標NEVER，第一次成功發布才記時間並成KNOWN。公開結果對UNKNOWN回空時間，UI顯示「首次刊登時間待核對」，不冒稱剛上架；授權更正服務尚未完成。

私人列表GET /me/listings支援status、limit 1～50（預設20）、cursor。只按本人id穩定分頁，不承諾變動中的快照；換status要清cursor。回摘要，不含私人地址／聯絡。此為私人列表，不是公開搜尋／地圖游標。

## 公開與圖片

GET /listings/:publicId只讀白名單投影，重核目前狀態／限制／帳戶與持久證據，不含私有地址、精確座標、Email、內部關係或物件URL。投影有多餘私有欄位／錯路徑則停止輸出。僅行政區表示，不宣稱C08地圖反推驗收完成。

地區以publicationPolicy的OPEN／STOP_NEW／NOT_OPEN判斷；舊布林isEnabled不猜三態，遷移資料先標UNKNOWN不開新刊。STOP_NEW保留既有合規公開但不能下架後重刊；NOT_OPEN／UNKNOWN不出公開結果。

公開圖片路徑在投影images列出；圖片讀取前後都檢查目前有效版本。下架／回收同交易撤投影，後續JSON與圖片入口404。暫採no-store；未設CDN或永久公開bucket，不承諾能撤回用戶已下載的副本。
