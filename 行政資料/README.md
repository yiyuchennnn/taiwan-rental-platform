## 版本與維護規則

1. 01定義範圍，02定義產品商業行為；03～12承接系統、資料、安全、驗收及營運要求。衝突須核對來源並修正，不以舊程式或舊討論覆蓋現行條文。
2. 已採用的規則直接更新主章；進度只放狀態與證據連結，不另複製一套商業規則。新修訂紀錄放歷史目錄，主文件不再堆疊整段批次日誌。
3. 「規劃已寫」不等於「已實作／測試通過／外部已驗證」。11/11既有後端277項測試、歷史269項與全平台67組驗收情境是不同事物，不代表全平台通過。
4. 舊討論沿用當時D01／D02；現行技術決策採PLAN-D01～PLAN-D04（原總覽D01～D04依序對應），跨章引用使用完整代號。零增量交接及暫停續扣已結案，不再因舊草案重開；現行預算、UI、保存恢復、外部人力仍待資料。
5. docs/api、docs/database、docs/decisions、docs/reports保留工程說明及證據；它們不具有覆蓋01～12的產品決策效力。其歷史測試與暫定設定須按原日期閱讀。
