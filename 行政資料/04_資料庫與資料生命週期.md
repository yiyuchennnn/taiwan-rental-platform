# 04 資料庫與資料生命週期

版本：2026-11-07詳細設計整合版，承接02的R02～R09、C04～C12。現有欄位只是部分實作；下列新增概念是目標模型，未修改schema或執行migration。跨章狀態見 [總覽](進度與待辦/03至12_規劃總覽與決策清單.md)。

## 04-01 事實與模型

| 資料群 | 已存在基礎 | 後續必備模型／不變條件 |
| --- | --- | --- |
| 帳號／登入 | User、AuthSession、isActive | 外部身分綁定、分項查核、帳戶生命週期及撤回事件；isActive不能代表全部狀態 |
| 房源／位置 | Listing、Property、DraftAddress、City／District | 私人地址、工作／公開版本、地區三態、同單位查核及公開關聯同意分開；地址相同不自動同房 |
| 房源明細 | 費率／設備／費用子表及部分三態 | 費用比例、必要／選配、來源、週期與型態必填可原值保存；未知與否不同 |
| 圖片／儲存 | ListingMedia、MediaAsset、MediaUpload | 帳戶資產權屬／引用、各尺寸bytes、正式用量／操作預留／平台暫存分開、換圖操作與清理證明 |
| 方案資格 | EntitlementAccount／Period | 付費／贈送／推薦排程、逐來源價值、六類臨時加額、寬限與保留選擇；不產生重疊消耗 |
| 支付／退款 | 尚無完整模型 | 訂單、付款嘗試、供應商事件、實付來源分配、報價、退款請求／送出／結果及對帳；款項與權益分開 |
| 公開內容 | 尚無完整文章／品牌模型 | Article／Brand、公開識別與版本、平台／會員作者權限、收藏及比較的公開引用；不存私有快照作收藏 |
| 營運／工作 | 部分圖片工作 | Operation、Outbox／Job、Notification、Report／Appeal、Audit；同業務事件／收件管道唯一，重試留歷史 |
| 政策資料 | 行政資料 | 租補政策版本／生效區間／來源、公開位置規則版本、價目與欄位規格版本 |

概念關聯：User→Listing／Article／Brand；Listing→私人地址與明細→工作版本→公開版本；帳戶→合法資產權屬→多個引用；訂單→實付來源→資格段／升級→退款；事件→工作→外部結果。Property內部關聯不能取代C09公開合組證據。

## 04-02 資料字典共通約定

- 金額整元用整數；租屋費率／比例／面積按02精度用decimal，不用浮點累積。訂閱中間價值保留有理數或足夠精度decimal與原分子分母，不每段先取整。bytes使用可精確整數，API以十進位字串傳遞，避免JS安全整數損失。
- 時間UTC且保留事件來源，日期與瞬間分型；價目、規則版本及引用依據不可只保留「目前價格」。不可空值與業務未填分開；null不自動代表0、否、從未公開或免費。
- 私有／公開資料以白名單生成，不能把完整ORM物件交前端。證明、交易及私有位置採最小存取；公開識別不包含門牌或可還原座標。
- 集合更新：未送保留、[]明確替換為空，允許null的純量才可清；混用新舊表示不得互相矛盾。參照的外鍵／操作者由後端取得，不信任請求指定。
- 查核狀態分項、到期僅依可信來源；所有更正留原值、新值、來源、理由、操作者及時間。Audit不可由一般CRUD任意刪改，另有依法清理程序，不宣稱個資永久保存。

## 04-03 約束與一致性

1. 單一刊登恰一封面在發布時成立，草稿可0圖；同位置只一有效引用，排序不重複。DB唯一／外鍵約束與服務驗證一起保護，不只靠前端。
2. 跨帳戶資產權屬各自計量，底層去重不等於免容量；同帳戶同資產多引用一次計量。最後引用移除在資產鎖內重核；仍被引用者不可清除；已進入禁止新引用的清理階段或永久刪除已承諾者不可新引用。
3. 一段資格來源及供應商付款事件唯一；退款已退＋送出待結果不超實付。推薦每個有效新會員事件唯一，原台灣年度成立名額最多12；撤銷釋回原年度。
4. 公開／草稿／封存六類各自計量，平台限制獨立；狀態事實為主，快取計數可重建並定期對帳，不以可變計數器直接當唯一真相。
5. 首刊一般修改不可變。現有防改trigger須保留安全邊界，另設只供授權更正的受控路徑，驗證R05證據並同交易保存Audit；不能給一般服務一個可隨意開的bypass旗標。
6. 公開版本、隱私版本、規則版本與內容revision同時提交。索引／快取可以晚更新，公開讀取不可供應已撤銷版本。
7. P01以接收者正式權屬及實際新增bytes證明N=0；不依hash或發起者刪量。P02暫停與續扣授權是不同資料；恢復不重啟已取消授權，不改未取消原安排。

## 04-04 生命週期與清除

| 資料 | 開始／結束與保存 | 清理或恢復要求 |
| --- | --- | --- |
| 草稿／封存 | 依本人管理與02額度，不因超額自刪 | 無關編輯保留舊語意；合規轉換再重核 |
| 回收內容 | 此次入回收起30×86400秒 | 截止前完成且未承諾永久刪除才可恢復；一般回封存需空位，受限回限制不需封存空位 |
| 帳戶刪除 | 本人確認申請起30天可撤回 | 停公開、取消未來續扣追蹤；撤回不復刊、不復活已永久刪資產 |
| 正式圖片 | 存在有效引用／待實際清理仍計量 | 清除正式各尺寸後釋容量；權屬移轉的帳戶扣量與實體刪除分開 |
| 原圖／平台暫存／失敗殘留 | 不長期保存、不算會員正式容量 | 暫存上限、到期、隔離與實際清理時效須E02成本驗證，未知不得開無限暫存 |
| 付款／查核／案件／Audit | 依合法用途與保存清單 | 到期去識別或清理；法律保全有原因、權限、範圍與解除日期，不一律永久保留 |
| 備份／快取 | 非會員可恢復版本庫 | 保留期須12核定；備份復原重套刪除標記及撤銷，不復活已刪／不安全公開 |

除02既定30天外，交易、證件、證據、暫存、備份的具體保存期不在本輪臆定。清單須列資料類型、用途、管理者、最短／最長期限、清理與保全例外；未完成則相應正式查核、清理及收費上線受阻。

## 04-05 遷移與舊資料

- 既有15個migration保留歷史，不重寫已可能套用檔案；後續採先加可相容欄位→明確來源回填→雙版本讀取驗證→切換→另批移除的順序。
- SUITE、RESIDENTIAL_BUILDING、areaType、舊四位面積／租期文字／publishedAt不猜新語意；首刊分可信、未知、從未公開，不以匯入時間回填。
- 正式變更前備份及去識別副本演練；記錄筆數、唯一／外鍵、來源對應、容量、金額及角色前後差異。對帳不符停止切換，不靠刪資料令migration通過。
- 危險約束先盤點不合資料，提供可回報修正；變更不能令無關舊資料編輯永久失敗。資料轉型／刪欄屬獨立不可逆門檻，不能由啟動腳本自動reset。

## 04-06 完成證據

待實作交付：ERD與欄位字典、唯一性／鎖及狀態不變條件、來源與保存清單、遷移正反／備份還原演練、合法更正／刪除對帳。只有schema或空表不算流程完成；本章未宣稱實際資料已轉換。

## 04-07 目標邏輯資料字典

下列為設計名稱，不表示同名SQL表已存在；實作可調整實體名稱，不能遺失欄位語意。識別不可重用；時間欄位分occurredAt（來源事件）、recordedAt（平台記錄）及effectiveAt（業務生效），晚到事件不倒改已確認結果。

| 資料主體 | 必備事實 | 唯一性／關聯與生命週期 |
| --- | --- | --- |
| AccountLifecycle | accountId、目前狀態、revision、申請與截止、原因參照 | ACTIVE／PAUSED／SUSPENDED／DELETION_PENDING／DELETED；帳戶狀態不取代內容限制 |
| VerificationFact | 主體、查核種類、範圍／聯絡版本、狀態、來源、核准與失效時間 | 同一主體及種類可留歷史；使用時取適用有效版本，改電話不沿用舊電話控制權 |
| CapabilityGrant | 人員、能力、範圍、有效期、授予／撤銷者 | 有效授予可追溯；不得從ADMIN單值推出所有能力 |
| Content | id、類型、持有人、主狀態、restriction、revision、firstPublished事實 | Listing與Article各自識別；平台文章另標平台主體，不占會員文章額度 |
| WorkVersion／PublicVersion | contentId、內容revision、欄位規格版本、圖片引用、建立／提交者 | 每內容至多一個目前工作版及一個有效公開版；歷史僅按必要稽核保存，不承諾版本庫 |
| PublicationGuard | contentId、有效公開revision、privacyVersion、展示是否暫停、撤銷世代 | 公開入口必核對；暫停同步與主狀態不同，不能趁暫隱釋出名額 |
| Location／PublicLocation | 私人地址版本、核對來源；公開模式、區域版本、代表點與同意 | 真地址不在公開表；地址變更使原同意及定位結果不再適用 |
| UnitReview／PublicGroup | 候選、證據參照、判定、各成員及同意版本 | 內部同單位與公開合組兩套關聯；不同意不得由群組ID洩漏 |
| Asset／AccountAsset／Reference | 物理資產尺寸bytes、帳戶合法權屬、內容與位置引用 | 帳戶＋資產唯一計量；不同帳戶各計。引用包含工作／公開／回收必要位置 |
| CapacityEntry／Reservation | accountId、operationId、資產、增減bytes、原因、狀態 | 同一結算效果唯一；預留、平台暫存、正式帳分別保存，不能一欄混算 |
| Quote／Order／PaymentAttempt | 規則價目版本、來源分配、確認摘要、金額幣別、期限、供應商參照 | 一份報價不可重複成交；一次訂單可有明確失敗後的新嘗試，未知嘗試不能再扣 |
| PaymentSource／Allocation | 實付金額、可退來源、所屬資格／升級及精確分配 | 分配總和等於來源；優惠與贈送不能變現金來源 |
| EntitlementSegment／Schedule | 來源、方案、S／E、計費錨點、價表版本、替代關係、排程revision | 同時僅一條消耗路徑；已替代段不能再次使用或折抵 |
| TemporaryQuotaGrant | 六類增量、確認、生效／截止、原因與核准 | 與方案段獨立，無GB或工具增量；重送不重新起算 |
| RenewalMandate | 供應商授權參照、同意版本、方案／週期／日期、變更與取消結果 | ACTIVE／CHANGE_PENDING／CANCEL_PENDING／CANCELLED等結果分開；暫停帳戶不改授權 |
| Refund／Dispute | 選定來源、終止時點、精確應退、已保留／送出／確認、供應商參照 | 來源累計退款進位及上限按C06；爭議款與退款共同對帳，不雙返 |
| Reward | 被推薦者首次有效付款參照、M／Y、名額狀態、領取與轉換結果 | 每被推薦者最多一筆有效獎勵；年度名額鎖定原年，補償另分類 |
| GraceEpisode | 帳戶、內容類別、原因、起止、預選及本人選擇revision | 每類同時一個有效超額事件；新增原因不延長原截止 |
| Transfer | 內容、雙方、邀請／截止、預覽revision、目標狀態、確認 | 一次一筆，完成只一次；歷史操作者不可改成新持有人 |
| Operation／Outbox／Job | 操作主體、key摘要、結果、事件、嘗試／lease／epoch | 詳07；同業務操作可多次嘗試，不能多次生效 |
| Case／Audit／Notification | 主體、原因、最少證據、處置／覆核、事件與管道 | Audit更正用新記錄；通知投遞狀態與會員是否閱讀分開 |
| PolicyVersion | 地區年度、規則來源、有效區間、核對人／日期 | 租補填答不持久化；規則與結果模板有版本，無可信規則不試算 |

## 04-08 狀態與計數的確定規則

主狀態為DRAFT／PUBLISHED／ARCHIVED／TRASHED／DELETED；平台限制是獨立層，記原狀態與案件。計數時先判主狀態回收／永久刪除，再判有效平台限制，最後才計草稿／公開／封存。房源與會員文章分別套用；品牌不占這六類。

| 有效狀態 | 計數桶 | 公開條件 |
| --- | --- | --- |
| TRASHED／DELETED（即使保留restriction） | 回收／永久刪除獨立管理，不占六類 | 不公開；永久刪除已承諾不可再引用 |
| 非回收且內容限制有效 | 限制獨立管理，不占六類 | 不公開；原主狀態只供解除時判斷 |
| 無限制DRAFT／ARCHIVED | 草稿／封存各一筆 | 不公開 |
| 無限制PUBLISHED且純隱私同步暫停 | 仍占公開一筆 | 同步完成並重核前不展示 |
| 無限制PUBLISHED且展示條件皆有效 | 公開一筆 | 僅有效公開版可讀 |

帳戶暫停／停權／刪帳時，原公開內容必要下架轉封存（可超額），不是將每筆改成內容違規。解除內容限制：原草稿且有位回草稿，否則必要轉封存可超額；仍在回收區的不因解除限制復活，之後一般恢復按封存空位。發布中／工作版不另占草稿，預留也不是第二筆內容。

## 04-09 版本、費用與舊資料的落地規則

內容revision在每次有效修改或狀態／持有人變更遞增；無變更的重送不增加。公開版綁定通過檢查的內容、聯絡、圖片、位置與同意版本；部分更新先合併有效工作值，再驗被變動的相依欄位。現行多層以去重後floors清單表示，不要求連續樓層；舊floorFrom／floorTo只作相容讀取，改寫樓層組時必須轉為本人確認的現行表示。模式切換不得留下互相矛盾的欄位，也不自動把歷史未知猜為答案。

租屋固定費採一份標準化費用明細：種類、必要／選配、含租／免收／固定／按量、整期金額／費率／比例、頻率、支付時點、收款對象、說明及來源欄位。水電由各自kind連結費用事實；管理／車位等不能又在舊純量與新明細各加一次。服務費比例及押金倍數另保存原值與純月租基準；畫面合計為衍生值，不作第二個可任改金額。未知必要固定費不可發布，季節水電只說明不生成虛構費率。

工作版和公開版引用同資產，容量按帳戶資產去重；放棄工作版只移除它的引用，不能刪仍在公開版的圖。已被取代的版本可留最少稽核摘要，不自動形成舊圖有效引用或可恢復版本庫；已確認的指定位置換圖須同步切換該位置的有效展示引用，其他內容的合法引用仍保留。替換切換前後的可讀引用和暫存歸屬依C12，不因建立公開快照重計一次容量。

舊SUITE、舊樓層、舊四位小數及自由文字可保留原值與legacy標示，無關文字修改不強迫錯誤轉換；改到該組或重新發布時要求確認現行表示。新API只接受現行欄位規格；歷史相容讀取與現行發布檢查分開，不以舊測試拒絕新合法型態。

## 04-10 保存清單與清除責任

| 類型 | 觸發／主責 | 到期行為與外部待驗 |
| --- | --- | --- |
| 內容回收、刪帳撤回 | 02既定30天；內容／帳戶服務 | 截止不可恢復，進清理；另案證據不以會員引用保留 |
| 登入／一次性憑證 | 06到期或撤銷；安全維運 | 立即失去授權效力，清除記錄期限列D03，不以清除延誤延長登入 |
| 工作與上傳暫存 | 操作終止且確認寫入隔離；圖片維運 | 無參考且可安全清才清；實際期限與平台上限列E02 |
| 交易、退款、Audit及證據 | 用途結束／案件終結；帳務／查核責任人 | 保存期及保全依E05核定；保全須範圍、到期複核，禁止一律永久留存 |
| 備份與防復活紀錄 | 備份到期及復原範圍；工程維運 | 防復活記錄須涵蓋可恢復的備份窗口；最小識別不含被刪內容正文 |
| 訪客定位／租補填答 | 當次查詢；網站／政策服務 | 不持久保存原始座標或資格填答，不進URL／日誌／分析事件；一般安全日誌另依保存清單 |

D03未結案前，測試使用合成資料，可繼續文件與介面設計；不得因此對外收證件或宣稱具正式資料保存能力。
