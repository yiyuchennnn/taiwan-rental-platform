# 04 資料庫與資料生命週期

版本：2026-11-07規劃基準，承接02的R02～R09、C04～C12。現有欄位只是部分實作；下列新增概念是目標模型，未修改schema或執行migration。跨章狀態見 [總覽](03至12_規劃總覽與決策清單.md)。

## 04-01 事實與模型

| 資料群 | 已存在基礎 | 後續必備模型／不變條件 |
| --- | --- | --- |
| 帳號／登入 | User、AuthSession、isActive | 外部身分綁定、分項查核、帳戶生命週期及撤回事件；isActive不能代表全部狀態 |
| 房源／位置 | Listing、Property、DraftAddress、City／District | 私人地址、工作／公開版本、地區三態、同單位查核及公開關聯同意分開；地址相同不自動同房 |
| 房源明細 | 費率／設備／費用子表及部分三態 | 費用比例、必要／選配、來源、週期與型態必填可原值保存；未知與否不同 |
| 圖片／儲存 | ListingMedia、MediaAsset、MediaUpload | 帳戶資產權屬／引用、各尺寸bytes、正式用量／操作預留／平台暫存分開、換圖操作與清理證明 |
| 方案資格 | EntitlementAccount／Period | 付費／贈送／推薦排程、逐來源價值、六類臨時加額、寬限與保留選擇；不產生重疊消耗 |
| 支付／退款 | 尚無完整模型 | 訂單、付款嘗試、供應商事件、實付來源分配、報價、退款請求／送出／結果及對帳；款項與權益分開 |
| 公開內容 | 尚無完整文章／品牌模型 | Article／Brand、公開識別與版本、平台／會員作者權限、收藏及比較的公開引用；不存私有快照作收藏 |
| 營運／工作 | 部分圖片工作 | Operation、Outbox／Job、Notification、Report／Appeal、Audit；同業務事件／收件管道唯一，重試留歷史 |
| 政策資料 | 行政資料 | 租補政策版本／生效區間／來源、公開位置規則版本、價目與欄位規格版本 |

概念關聯：User→Listing／Article／Brand；Listing→私人地址與明細→工作版本→公開版本；帳戶→合法資產權屬→多個引用；訂單→實付來源→資格段／升級→退款；事件→工作→外部結果。Property內部關聯不能取代C09公開合組證據。

## 04-02 資料字典共通約定

- 金額整元用整數；租屋費率／比例／面積按02精度用decimal，不用浮點累積。訂閱中間價值保留有理數或足夠精度decimal與原分子分母，不每段先取整。bytes使用可精確整數，API以十進位字串傳遞，避免JS安全整數損失。
- 時間UTC且保留事件來源，日期與瞬間分型；價目、規則版本及引用依據不可只保留「目前價格」。不可空值與業務未填分開；null不自動代表0、否、從未公開或免費。
- 私有／公開資料以白名單生成，不能把完整ORM物件交前端。證明、交易及私有位置採最小存取；公開識別不包含門牌或可還原座標。
- 集合更新：未送保留、[]明確替換為空，允許null的純量才可清；混用新舊表示不得互相矛盾。參照的外鍵／操作者由後端取得，不信任請求指定。
- 查核狀態分項、到期僅依可信來源；所有更正留原值、新值、來源、理由、操作者及時間。Audit不可由一般CRUD任意刪改，另有依法清理程序，不宣稱個資永久保存。

## 04-03 約束與一致性

1. 單一刊登恰一封面在發布時成立，草稿可0圖；同位置只一有效引用，排序不重複。DB唯一／外鍵約束與服務驗證一起保護，不只靠前端。
2. 跨帳戶資產權屬各自計量，底層去重不等於免容量；同帳戶同資產多引用一次計量。最後引用移除在資產鎖內重核；仍被引用或永久刪除已承諾者不可新引用。
3. 一段資格來源及供應商付款事件唯一；退款已退＋送出待結果不超實付。推薦每個有效新會員事件唯一，原台灣年度成立名額最多12；撤銷釋回原年度。
4. 公開／草稿／封存六類各自計量，平台限制獨立；狀態事實為主，快取計數可重建並定期對帳，不以可變計數器直接當唯一真相。
5. 首刊一般修改不可變。現有防改trigger須保留安全邊界，另設只供授權更正的受控路徑，驗證R05證據並同交易保存Audit；不能給一般服務一個可隨意開的bypass旗標。
6. 公開版本、隱私版本、規則版本與內容revision同時提交。索引／快取可以晚更新，公開讀取不可供應已撤銷版本。
7. P01以接收者正式權屬及實際新增bytes證明N=0；不依hash或發起者刪量。P02暫停與續扣授權是不同資料；恢復不重啟已取消授權，不改未取消原安排。

## 04-04 生命週期與清除

| 資料 | 開始／結束與保存 | 清理或恢復要求 |
| --- | --- | --- |
| 草稿／封存 | 依本人管理與02額度，不因超額自刪 | 無關編輯保留舊語意；合規轉換再重核 |
| 回收內容 | 此次入回收起30×86400秒 | 截止前完成且未承諾永久刪除才可恢復；一般回封存需空位，受限回限制不需封存空位 |
| 帳戶刪除 | 本人確認申請起30天可撤回 | 停公開、取消未來續扣追蹤；撤回不復刊、不復活已永久刪資產 |
| 正式圖片 | 存在有效引用／待實際清理仍計量 | 清除正式各尺寸後釋容量；權屬移轉的帳戶扣量與實體刪除分開 |
| 原圖／平台暫存／失敗殘留 | 不長期保存、不算會員正式容量 | 暫存上限、到期、隔離與實際清理時效須E02成本驗證，未知不得開無限暫存 |
| 付款／查核／案件／Audit | 依合法用途與保存清單 | 到期去識別或清理；法律保全有原因、權限、範圍與解除日期，不一律永久保留 |
| 備份／快取 | 非會員可恢復版本庫 | 保留期須12核定；備份復原重套刪除標記及撤銷，不復活已刪／不安全公開 |

除02既定30天外，交易、證件、證據、暫存、備份的具體保存期不在本輪臆定。清單須列資料類型、用途、管理者、最短／最長期限、清理與保全例外；未完成則相應正式查核、清理及收費上線受阻。

## 04-05 遷移與舊資料

- 既有15個migration保留歷史，不重寫已可能套用檔案；後續採先加可相容欄位→明確來源回填→雙版本讀取驗證→切換→另批移除的順序。
- SUITE、RESIDENTIAL_BUILDING、areaType、舊四位面積／租期文字／publishedAt不猜新語意；首刊分可信、未知、從未公開，不以匯入時間回填。
- 正式變更前備份及去識別副本演練；記錄筆數、唯一／外鍵、來源對應、容量、金額及角色前後差異。對帳不符停止切換，不靠刪資料令migration通過。
- 危險約束先盤點不合資料，提供可回報修正；變更不能令無關舊資料編輯永久失敗。資料轉型／刪欄屬獨立不可逆門檻，不能由啟動腳本自動reset。

## 04-06 完成證據

待實作交付：ERD與欄位字典、唯一性／鎖及狀態不變條件、來源與保存清單、遷移正反／備份還原演練、合法更正／刪除對帳。只有schema或空表不算流程完成；本章未宣稱實際資料已轉換。
