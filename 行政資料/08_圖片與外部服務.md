# 08 圖片與外部服務

版本：2026-11-07規劃基準。R2是使用者已選的第一個正式儲存**驗證候選**，驗證桶不等正式桶；本輪不建立資源、不讀秘密、不呼叫服務或變更付費訂閱。服務商選擇不憑瀏覽器分頁猜測。

## 08-01 共同整合規範

每個adapter須有：用途、帳號／資源所有者、官方能力／條款與報價核對日、輸入最少資料、成功／未知／失敗分類、逾時、重試／查詢、防重送、停用及替代行為。未定供應商不得回傳假成功。

設定分環境、最小權限、秘密管理、精確回呼與outbound白名單；SDK可用不代表帳號有權。金鑰不貼對話、Git或日誌；應用失去依賴時保留原資料，不跳過驗簽或把未知當無上限。

## 08-02 圖片與R2

| 項目 | 規劃基準／現況 |
| --- | --- |
| 原檔 | JPG／PNG／WebP，真實內容驗證；最多10000000 bytes；動畫不接受，HEIC未通過E07不當支援 |
| 衍生圖 | 暫定展示最長1920、縮圖480、WebP品質82、小圖不放大；去GPS與位置metadata；代表性房源照片仍需比較 |
| 數量 | 房源草稿0～30、發布3～30且一封面；文章封面＋插入位置20；容量按資產而非位置 |
| 儲存 | 原圖不長期保存；正式展示／縮圖／必要衍生圖計會員bytes；平台暫存、失敗殘留、證據及備份分帳 |
| R2權限 | 專用環境資源、限定桶物件讀寫，不能拿管理員總金鑰給程式；私有命名空間與不可猜識別 |
| 公開存取 | 草稿／證明不開公開bucket／r2.dev；公開圖片須跟目前公開／隱私版本一致，可停止供應與撤除快取 |
| 清理 | durable proof、引用隔離、實際各尺寸刪完確認才釋量；復原與風險見07／11 |

- 正式公開配送先採受控圖片出口設計，不把永久物件URL當權限；CDN或簽名URL必須有可核對的到期／撤銷／cache策略，不能因下架只改API卻繼續無限供圖。精確到隱藏期間先阻不安全輸出，不承諾外部下載可撤。
- 使用者直接傳API／日後安全直傳都必須由後端驗權／內容／版本／配額；CORS不是授權，前端指定objectKey不具管理權。超大圖／解碼資源限制、格式偽裝與中途寫失敗要測。
- 同檔另上傳不承諾自動去重；跨帳戶權屬獨立。P01不能以底層R2去重或來源可清量假裝接收者N=0。
- 容量表須基於真照片及衍生圖、張數／筆數情境、回收／受限、頭像／Logo／卡片、換圖暫存及備份成本量測；不先編每方案GB。80%／100%與安全換圖規則已定，可信帳本未做。
- 既有一次驗證桶寫入／讀回／清除是歷史證據；正式桶、公開出口、負載、故障、權屬／計量、恢復及成本驗收必須另做。正式上傳仍預設關閉，R2環境變數存在不自動啟用。

## 08-03 金流及帳務

供應商未選。需證明：台幣單次付款及明確授權續扣、曆月／改期、取消、部分退款／查詢、交易唯一參照、webhook驗簽、重複／延遲／順序錯亂、爭議對帳及正式商戶資格。續扣順延是C05必要能力，不能假設一般訂閱SDK都有。

| 能力限制 | 必須採取 |
| --- | --- |
| 不能可靠順延贈送後扣款 | 不消耗獎勵、不宣稱順延完成；先核對，不用取消重建偷偷擴授權 |
| 付款已成但權益未開 | 查原筆補處理／退款，不叫客戶再付 |
| 退款太小或暫失敗 | 保留應退案件及人工可核對方式，不歸零或多退 |
| 交易結果未知 | 確認中／對帳，不用前端返回或查不到立刻當失敗 |
| 價格或授權條件改變 | 明確再確認；不按新價默扣，不截短原已購 |

發票／含稅、費率、撥款及爭議程序須E01／E05正式核對；本文件不作供應商價格或法律結論，不因此開收款。

## 08-04 郵件、Google／LINE與Bot

- 郵件需發信網域與SPF／DKIM／DMARC、交易寄送用途、退信／封鎖／查送達、資料處理與費用。必要通知與可取消一般資訊分開，不在模板放私有證據或秘密。
- Google／LINE登入需負責人所有的正式app、預備／正式回呼與審核範圍；少權限，不因同Email合併。第三方缺Email按R08補驗，不自行造Email。
- 聯絡控制權的方法須可驗證；SMS、Email或LINE能證明的範圍不同，不用LINE登入冒充知道電話，也不以點擊外部連結當控制權通過。
- Bot綁定與登入分開，驗簽、訊息去重、解除綁定、資格到期、照片與草稿位共用。未核對訊息額度／費用及權限不承諾可免費無限使用。

## 08-05 地圖、地址、設施與隱私

底圖、地理編碼、POI是三種能力，可不同來源但需各有授權／全台涵蓋／更新／快取／配額與費用。首發直線距離，路線時間排除；不得新加付費導航承諾。

- 私人定位與公開概略位置隔離，外部設施查詢盡量用公開代表位置；若定位必要傳真地址，記目的／來源／資料處理，原始回應不整包給訪客。
- C08區域大小、稀疏判準及版本變更須樣本反推測試後定，不憑任意幾百公尺宣稱保密；不每次隨機漂移，邊界／距離／計數／篩選同公開基準。
- 缺POI、定位疑義、供應商故障分開。地址可信但附近無資料可安全降級，不影響合規房源；真地址有疑義不發布。不能用真座標補公圖空缺。

## 08-06 影片、租補與檔案

YouTube／Vimeo僅02允許候選，逐一驗授權、禁嵌及隱私行為；不可嵌就安全原連結，不抓影片檔、不自動播。租補政策需官方地區／年度／生效條件／併領及版本維護人，未核對不提供假金額。Excel／CSV只範本資料，不執行巨集／公式，100列不等於可承受任意bytes。

## 08-07 供應商上線證據包

每項提供：負責人資源清單（非金鑰）、sandbox與正式差異、必要授權／條款與報價、資料流、失敗／回復實測、限額成本及告警、輪替／退出匯出方案。檢查結果日期與環境都要記錄；未具證據的正式能力保持關閉或按02降級，不能以「adapter已寫」結案。
